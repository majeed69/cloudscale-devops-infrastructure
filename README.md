# CloudScale DevOps Infrastructure

Production-ready DevOps infrastructure project built using AWS, Linux, Nginx, GitHub Actions, Load Balancer, and Auto Scaling.

## Features
- CI/CD with GitHub Actions
- AWS EC2 Deployment
- Nginx Reverse Proxy
- Path-Based Routing
- Load Balancing
- Auto Scaling
- Linux Server Administration
